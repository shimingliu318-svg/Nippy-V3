# Nippy V3

Nippy V3 is a small 12-degree-of-freedom quadruped robot that can walk, sing, dance, and chat. The build cost was under US$70.

## Downloads

The [Nippy V3 release](https://github.com/shimingliu318-svg/Nippy-V3/releases/tag/firmware-first) contains the files for building and programming the robot.

- Standalone dance and factory online firmware
- Schematic and PCB PDFs, plus Gerber files
- English bill of materials and assembly accessories list
- 3D-printable STL files with English filenames
